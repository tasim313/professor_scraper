# Security Policy

## Supported Versions
Security updates are provided only for the latest stable release of the Global Academic Intelligence Platform. 

## Data Privacy & GDPR Compliance
Because this platform aggregates public academic data, we adhere to strict ethical scraping and privacy guidelines:
- **Public Data Only**: We exclusively scrape public-facing, professional academic profiles. We do not scrape or store personal contact information (e.g., home addresses, personal phone numbers).
- **Opt-Out Mechanism**: Any researcher or university can request data removal or correction via our primary contact email.
- **Source Attribution**: All data records in our database contain a `source_url` pointing to the original origin of the data, ensuring provenance.

## Vulnerability Reporting
If you discover a security vulnerability within the platform (including the Django API, Scraper Engine, or Next.js Frontend), please DO NOT open a public issue.

Instead, please send an email to the repository maintainers with the following:
1. Description of the vulnerability.
2. Steps to reproduce.
3. Potential impact.

**Response Time**: We aim to acknowledge receipt of vulnerability reports within 48 hours and provide a timeline for resolution.
